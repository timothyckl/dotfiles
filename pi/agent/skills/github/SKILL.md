# GitHub Router

Read only the child skills needed for the request:

- Issues: [github-issues](github-issues/SKILL.md)
- Branches: [github-branches](github-branches/SKILL.md)
- Commits: [github-commits](github-commits/SKILL.md)
- Pull requests: [github-pull-requests](github-pull-requests/SKILL.md)
- Actions, checks, or CI failures: [github-actions](github-actions/SKILL.md)

For work spanning multiple areas, read each applicable skill. Do not load unrelated child skills.
