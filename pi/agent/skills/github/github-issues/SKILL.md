# GitHub Issues

1. Confirm the repository and inspect relevant existing issues before acting.
2. When creating an issue, inspect repository issue templates and available labels when relevant.
3. Keep the title concise and under 72 characters.
4. Include a brief summary in the body. For bugs, include steps to reproduce.
5. Use `gh issue` to inspect, create, or update the issue.
6. Change only the fields requested, and report the resulting issue URL or state.
