# GitHub Commits

1. Inspect `git status`, the relevant diff, and recent commit style before acting.
2. Stage only files belonging to the requested change.
3. Format the subject as `<type>[optional scope]: <description>`.
4. Keep the description concise, imperative, lowercase, and focused on why.
5. Keep logically distinct changes in separate commits.
6. Do not amend, rewrite, or push commits unless explicitly requested.
7. Report the resulting commit hash and subject.
